TP : Développement d’une application Spring Boot MVC avec Thymeleaf

Manipulation des expressions, conditions, boucles, objets utilitaires et navigation sûre dans les templates Thymeleaf.

Objectifs du TP

  • Créer une application web basée sur l’architecture Spring Boot MVC.
  • Transmettre des données du contrôleur vers une vue Thymeleaf avec ${...}.
  • Construire des liens dynamiques avec @{...} et réutiliser des fragments avec ~{...}.
  • Utiliser les conditions th:if et th:unless.
  • Parcourir une collection avec th:each, y compris avec une condition.
  • Manipuler des chaînes de caractères avec l’objet utilitaire #strings.
  • Éviter les erreurs d’accès à des propriétés nulles avec l’opérateur de sûreté ?..
Contexte : vous allez développer une petite application de gestion des étudiants. Elle affichera une liste d’étudiants, leurs informations, leur statut et leurs résultats.

Préparation – Création du projet

1. Création du projet Spring Boot

Créer un projet Maven avec Spring Initializr ou votre environnement de développement.

Paramètres conseillés :

  • Project : Maven
  • Language : Java
  • Packaging : Jar
  • Java : 17 ou version compatible avec la version de Spring Boot utilisée
  • Group : com.example
  • Artifact : gestion-etudiants

2. Dépendances Maven

Ajouter les dépendances suivantes dans le fichier pom.xml (ou les sélectionner lors de la création du projet) :

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-thymeleaf</artifactId>
    </dependency>
</dependencies>

Rôle : spring-boot-starter-web fournit Spring MVC et le serveur web embarqué ; spring-boot-starter-thymeleaf intègre le moteur de templates Thymeleaf.

public class Adresse {

Important : les getters et setters sont nécessaires pour permettre à Thymeleaf et à Spring Expression Language d'accéder aux propriétés des objets Java. Vous pouvez les générer avec votre IDE.

Partie 1 – Expressions Thymeleaf

Variable ExpressionLink URL ExpressionFragment Expression

1.1. Préparer le contrôleur

Créer EtudiantController. Dans la méthode ci-dessous, construire une liste de quelques étudiants et la transmettre à la vue.

@Controller
public class EtudiantController {

    @GetMapping("/etudiants")
    public String afficherEtudiants(Model model) {

        List<Etudiant> etudiants = new ArrayList<>();

        // Créer et ajouter au moins 4 étudiants
        // avec des notes, niveaux et statuts différents.

        model.addAttribute("etudiants", etudiants);
        model.addAttribute("titre", "Gestion des étudiants");
        model.addAttribute("message", "Bienvenue dans l'application");

        return "etudiants";
    }
}

1.2. Expression ${...} – Variable Expression

Dans le template etudiants.html, afficher le titre et le message transmis par le contrôleur.

<!DOCTYPE html>
<html lang="fr" xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Étudiants</title>
</head>
<body>
    <h1 th:text="${titre}">Titre par défaut</h1>
    <p th:text="${message}">Message par défaut</p>
</body>
</html>
Travail demandé :
  1. Expliquer le rôle de model.addAttribute().
  2. Afficher le nom et l'email d'un étudiant en utilisant ${etudiant.nom} et ${etudiant.email}.
  3. Tester l'accès à l'URL http://localhost:8080/etudiants.

1.3. Expression @{...} – Link URL Expression

Cette expression permet de construire des URL en tenant compte du contexte de l'application.

Ajouter dans la page un lien vers la liste des étudiants :

<a th:href="@{/etudiants}">Afficher les étudiants</a>

Ajouter ensuite un lien de consultation pour chaque étudiant. L'URL devra contenir son identifiant :

<a th:href="@{/etudiants/{id}(id=${e.id})}">
    Consulter
</a>

Créer dans le contrôleur une méthode qui reçoit cet identifiant :

@GetMapping("/etudiants/{id}")
public String detail(@PathVariable Long id, Model model) {
    // Créer un etudiant avec id = 4
    // Ajouter l'étudiant au Model avec la clé "etudiant"
    return "detail";
}
Travail demandé :
  1. Créer la vue detail.html pour afficher les informations de l'étudiant.
  2. Ajouter dans cette vue un lien de retour vers /etudiants.
  3. Expliquer la différence entre une URL écrite directement dans href et une URL construite avec th:href.

1.4. Expression ~{...} – Fragment Expression

Un fragment est une partie d'une page HTML réutilisable dans plusieurs templates. L'expression de fragment Thymeleaf s'écrit ~{...}.

Créer le fichier templates/fragments/header.html :

<header th:fragment="entete">
    <h1>Application de gestion des étudiants</h1>
    <nav>
        <a th:href="@{/etudiants}">Liste des étudiants</a>
    </nav>
    <hr>
</header>

Insérer le fragment dans etudiants.html :

<div th:replace="~{fragments/header :: entete}"></div>
Travail demandé :
  1. Insérer le même fragment dans detail.html.
  2. Ajouter un fragment de pied de page et l'utiliser dans les deux vues.
  3. Expliquer l'intérêt de th:fragment et de th:replace.

Partie 2 – Conditions, boucles et objets utilitaires

th:ifth:unlessth:each#strings

2.1. Conditions avec th:if et th:unless

th:if affiche un élément lorsque la condition est vraie. th:unless affiche l'élément lorsque la condition est fausse.

Dans la vue, afficher un message en fonction du statut de l'étudiant :

<span th:if="${e.actif}">Compte actif</span>
<span th:unless="${e.actif}">Compte inactif</span>

Afficher également le résultat en fonction de la note :

<span th:if="${e.note >= 10}">Admis</span>
<span th:unless="${e.note >= 10}">Non admis</span>
Travail demandé :
  1. Afficher « Excellent » lorsque la note est supérieure ou égale à 16.
  2. Afficher « À améliorer » lorsque la note est inférieure à 10.
  3. Afficher un message spécifique pour les étudiants actifs et inactifs.
  4. Combiner deux conditions avec and : afficher « Étudiant actif et admis » si l'étudiant est actif et possède une note supérieure ou égale à 10.

2.2. Boucle avec th:each

Utiliser th:each pour parcourir la liste d'étudiants et générer une ligne de tableau par étudiant.

<table border="1">
    <thead>
        <tr>
            <th>ID</th>
            <th>Nom</th>
            <th>Email</th>
            <th>Note</th>
        </tr>
    </thead>
    <tbody>
        <tr th:each="e : ${etudiants}">
            <td th:text="${e.id}"></td>
            <td th:text="${e.nom}"></td>
            <td th:text="${e.email}"></td>
            <td th:text="${e.note}"></td>
        </tr>
    </tbody>
</table>

Pour récupérer les informations de l'itération, ajouter une variable de statut :

<tr th:each="e, stat : ${etudiants}">
    <td th:text="${stat.count}"></td>
    <td th:text="${e.nom}"></td>
    <td th:text="${stat.first ? 'Premier' : ''}"></td>
</tr>

Propriétés utiles : stat.index (indice à partir de 0), stat.count (rang à partir de 1), stat.size (taille de la collection), stat.first, stat.last, stat.even et stat.odd.

Travail demandé :
  1. Ajouter une colonne « Rang » qui affiche stat.count.
  2. Ajouter une colonne « Position » qui affiche « Premier » pour le premier étudiant et « Dernier » pour le dernier.
  3. Afficher le nombre total d'étudiants à l'aide de stat.size ou de l'objet utilitaire #lists.

2.3. Objet utilitaire #strings

Thymeleaf fournit l'objet utilitaire #strings pour effectuer des opérations courantes sur les chaînes de caractères.

MéthodeRôleExemple
toUpperCase()Convertir en majuscules${#strings.toUpperCase(e.nom)}
toLowerCase()Convertir en minuscules${#strings.toLowerCase(e.email)}
length()Calculer la longueur${#strings.length(e.nom)}
isEmpty()Vérifier si la chaîne est vide${#strings.isEmpty(e.email)}
contains()Vérifier si une chaîne en contient une autre${#strings.contains(e.nom, 'a')}
replace()Remplacer une sous-chaîne${#strings.replace(e.nom, 'a', '@')}

Exemples à intégrer dans une ligne du tableau :

<td th:text="${#strings.toUpperCase(e.nom)}"></td>
<td th:text="${#strings.toLowerCase(e.email)}"></td>
<td th:text="${#strings.length(e.nom)}"></td>
<td th:text="${#strings.replace(e.nom, 'a', '@')}"></td>
Travail demandé :
  1. Afficher le nom de chaque étudiant en majuscules.
  2. Afficher son email en minuscules.
  3. Afficher le nombre de caractères de son nom.
  4. Remplacer la lettre « a » par « @ » dans le nom pour observer le résultat.
  5. Tester #strings.isEmpty() avec un email vide ou nul.

2.4. Boucle avec condition

Il est possible de combiner th:each et th:if afin de n'afficher que les éléments qui respectent une condition.

Exemple : afficher uniquement les étudiants admis.

<tr th:each="e : ${etudiants}" th:if="${e.note >= 10}">
    <td th:text="${e.nom}"></td>
    <td th:text="${e.note}"></td>
</tr>
Travail demandé :
  1. Afficher uniquement les étudiants ayant une note supérieure ou égale à 10.
  2. Afficher uniquement les étudiants actifs.
  3. Afficher les étudiants actifs ayant une note supérieure ou égale à 12.
  4. Créer un tableau distinct contenant uniquement les étudiants de niveau « L3 ».
Attention : placer th:if sur le même élément que th:each permet de contrôler l'affichage de chaque élément parcouru. Pour une logique de filtrage métier réutilisable ou une grande collection, effectuer de préférence le filtrage dans le service ou le contrôleur.

Partie 3 – Opérateur de sûreté (Safe Navigation Operator)

3.1. Comprendre le problème des valeurs null

Une propriété d'un objet Java peut ne pas être renseignée et contenir la valeur null. Un accès direct à une propriété imbriquée peut alors provoquer une erreur d'évaluation.

Exemple : si etudiant.adresse vaut null, l'expression suivante n'est pas sûre :

<p th:text="${etudiant.adresse.ville}"></p>

3.2. Utiliser l'opérateur ?.

L'opérateur de navigation sûre permet de vérifier qu'un objet intermédiaire n'est pas nul avant d'accéder à sa propriété.

<p th:text="${etudiant.adresse?.ville}"></p>
  • Si adresse existe, l'expression récupère sa propriété ville.
  • Si adresse vaut null, l'expression renvoie null au lieu de tenter l'accès à ville.
Précision technique : dans cet exemple, ?. est l'opérateur de navigation sûre de Spring Expression Language (SpEL), utilisé dans les expressions Thymeleaf avec Spring.

3.3. Mise en pratique

Dans les données de test, créer au moins un étudiant avec une adresse renseignée et un autre sans adresse.

Etudiant e1 = new Etudiant();
e1.setNom("Ahmed");
e1.setAdresse(new Adresse());
e1.getAdresse().setVille("Agadir");

Etudiant e2 = new Etudiant();
e2.setNom("Salma");
e2.setAdresse(null);

Dans le template, afficher le nom et la ville :

<tr th:each="e : ${etudiants}">
    <td th:text="${e.nom}"></td>
    <td th:text="${e.adresse?.ville}"></td>
</tr>

3.4. Combiner navigation sûre et valeur par défaut

L'opérateur Elvis ?: permet de fournir une valeur de remplacement lorsque le résultat est nul.

<td th:text="${e.adresse?.ville ?: 'Ville non renseignée'}"></td>

Si l'adresse ou la ville est absente, le template affiche « Ville non renseignée ».

Travail demandé :
  1. Afficher la ville de chaque étudiant en utilisant ?..
  2. Remplacer une valeur nulle par le texte « Ville non renseignée » avec ?:.
  3. Tester le comportement avec une adresse existante et avec une adresse égale à null.
  4. Expliquer la différence entre ?. et ?:.
