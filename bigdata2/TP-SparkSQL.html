Thème : Analyse des performances académiques à partir d'un fichier CSV

Module : Big Data 2   |   Outil : Apache Spark / PySpark

from pyspark.sql import functions as F

df.select(
    F.count("*").alias("nombre_etudiants"),
    F.max("total_score").alias("score_max"),
    F.min("total_score").alias("score_min"),
    F.avg("total_score").alias("score_moyen")
).show()

6. Spark SQL : création et utilisation d'une vue

Principe : Une vue temporaire permet d'associer un nom à un DataFrame afin de l'interroger avec des instructions SQL. Elle est disponible pendant la durée de la session Spark et ne correspond pas à une table persistante enregistrée dans une base de données.

Manipulation 5 — Créer une vue temporaire

  1. Créer une vue temporaire nommée students à partir du DataFrame df.
  2. Afficher les données de cette vue avec une requête SQL.
  3. Afficher uniquement les colonnes student_id, total_score et grade.
df.createOrReplaceTempView("students")

spark.sql("""
    SELECT *
    FROM students
""").show()

À retenir : createOrReplaceTempView() crée la vue ou remplace une vue temporaire existante portant le même nom.

7. Requêtes SQL

Manipulation 6 — Sélection et filtrage

Exécuter les requêtes suivantes à l'aide de spark.sql() :

  1. Afficher toutes les lignes de la vue students.
  2. Afficher les étudiants ayant obtenu un score supérieur à 90.
  3. Afficher les étudiants ayant un taux de présence supérieur ou égal à 90 %.
  4. Afficher les étudiants ayant une note A ou B.
  5. Afficher les étudiants ayant entre 10 et 20 heures d'étude par semaine (bornes incluses).
  6. Afficher les étudiants dont la note est différente de F.
  7. Afficher les 10 étudiants ayant obtenu les scores les plus faibles.
spark.sql("""
    SELECT student_id, total_score, grade
    FROM students
    WHERE total_score > 90
    ORDER BY total_score DESC
""").show()

Manipulation 7 — COUNT, MAX, MIN, AVG et SUM

Écrire les requêtes SQL correspondantes :

  1. Compter le nombre total d'étudiants.
  2. Calculer le score maximal et le score minimal.
  3. Calculer le score moyen.
  4. Calculer la moyenne des heures de travail personnel.
  5. Calculer la moyenne de présence et de participation.
  6. Calculer la somme de tous les scores.
  7. Compter le nombre d'étudiants ayant obtenu un score au moins égal à 50.
spark.sql("""
    SELECT
        COUNT(*) AS nb_etudiants,
        MAX(total_score) AS score_max,
        MIN(total_score) AS score_min,
        AVG(total_score) AS score_moyen,
        SUM(total_score) AS somme_scores
    FROM students
""").show()

Manipulation 8 — GROUP BY et HAVING

Écrire et exécuter les requêtes SQL permettant de :

  1. Compter le nombre d'étudiants par grade.
  2. Calculer le score moyen par grade.
  3. Calculer, par grade, la moyenne des heures d'étude et de présence.
  4. Afficher les grades dont le nombre d'étudiants est supérieur à 100.
  5. Afficher les grades dont le score moyen est supérieur à 70.
  6. Classer les grades du score moyen le plus élevé au plus faible.
spark.sql("""
    SELECT
        grade,
        COUNT(*) AS effectif,
        AVG(total_score) AS score_moyen
    FROM students
    GROUP BY grade
    ORDER BY score_moyen DESC
""").show()

Manipulation 9 — Analyse croisée

Réaliser les analyses suivantes :

  1. Comparer le score moyen des étudiants ayant moins de 10 heures d'étude avec celui des étudiants ayant au moins 10 heures.
  2. Comparer le score moyen des étudiants dont la présence est inférieure à 75 % avec ceux dont la présence est au moins 75 %.
  3. Pour chaque grade, afficher le score moyen, la moyenne des heures d'étude et la moyenne de présence.
  4. Identifier les étudiants qui ont un score supérieur à la moyenne globale (utiliser une sous-requête).
  5. Afficher le nombre d'étudiants par grade, puis calculer la proportion de chaque grade dans l'effectif total (en pourcentage).

Indication : une sous-requête peut être utilisée pour calculer la moyenne globale :

SELECT student_id, total_score
FROM students
WHERE total_score > (
    SELECT AVG(total_score)
    FROM students
)

8. Créer une deuxième vue

Manipulation 10 — Vue des étudiants performants

  1. Créer une vue temporaire nommée high_performers contenant uniquement les étudiants dont le score est supérieur ou égal à 80.
  2. Afficher le contenu de cette vue.
  3. Compter les étudiants présents dans cette vue.
  4. Calculer le score moyen de ces étudiants.
  5. Afficher leur répartition par grade.
spark.sql("""
    CREATE OR REPLACE TEMP VIEW high_performers AS
    SELECT *
    FROM students
    WHERE total_score >= 80
""")
