Travaux pratiques : Spark MLlib

Thème : Prédiction et classification des performances académiques à partir d'un fichier CSV

Module : Big Data 2   |   Outil : Apache Spark / PySpark MLlib

1. Objectifs du TP

  • Charger et explorer un fichier CSV dans Spark.
  • Encoder une variable catégorielle avec StringIndexer.
  • Assembler les variables explicatives avec VectorAssembler.
  • Normaliser avec MinMaxScaler et standardiser avec StandardScaler.
  • Diviser les données en ensembles d'entraînement et de test (80/20).
  • Entraîner un modèle de classification avec LogisticRegression.
  • Évaluer un classifieur : Accuracy, F1, Precision, Recall.
  • Entraîner un modèle de régression avec LinearRegression.
  • Évaluer un régresseur : RMSE, MAE et R².
  • Comparer les modèles et synthétiser les résultats.

2. Contexte et jeu de données

Le fichier CSV contient des informations simulées sur les étudiants et leurs résultats académiques. Il permet d'étudier les liens entre l'assiduité, le travail personnel, la participation et la performance finale. L'objectif est double : classer les étudiants par grade (A, B, C, D, F) et prédire leur score final.

ColonneDescriptionType attendu
student_idIdentifiant unique de l'étudiantInteger
weekly_self_study_hoursHeures moyennes de travail personnel par semaine (0–40), distribution normale centrée sur 15 hDouble
attendance_percentageTaux de présence (50–100 %), distribution normale autour de 85 %Double
class_participationParticipation en classe (0–10), distribution normale centrée sur 6Double
total_scoreScore final (0–100), fonction des heures d'étude + bruit, borné entre 0 et 100Double
gradeNote catégorielle : A, B, C, D ou F, dérivée de total_scoreString
Fichier à utiliser : students.csv. Placez le fichier dans un répertoire accessible depuis votre environnement Spark. Adaptez le chemin utilisé dans le code aux emplacements de votre machine.
Attention : grade est dérivée de total_score. Pour la classification, on utilise grade comme étiquette et les autres variables (hors student_id et total_score) comme features. Pour la régression, on utilise total_score comme cible.

5. Préparation des features

Manipulation 2 — Encodage catégoriel avec StringIndexer

La colonne grade est catégorielle (A, B, C, D, F). Les algorithmes MLlib attendent des étiquettes numériques.

  1. Importer StringIndexer depuis pyspark.ml.feature.
  2. Créer un StringIndexer qui transforme grade en label.
  3. Appliquer le transformateur sur le DataFrame et afficher les colonnes grade et label pour vérifier la correspondance.
  4. Expliquer pourquoi StringIndexer attribue les indices par fréquence décroissante.
from pyspark.ml.feature import StringIndexer

indexer = StringIndexer(inputCol="grade", outputCol="label")
df_indexed = indexer.fit(df).transform(df)
df_indexed.select("grade", "label").distinct().show()

Manipulation 3 — Assemblage des features avec VectorAssembler

Les algorithmes MLlib attendent un vecteur unique de features.

  1. Définir la liste des colonnes explicatives : weekly_self_study_hours, attendance_percentage, class_participation.
  2. Créer un VectorAssembler qui produit la colonne features.
  3. Appliquer le transformateur et afficher les colonnes features et label.
from pyspark.ml.feature import VectorAssembler

feature_cols = ["weekly_self_study_hours", "attendance_percentage", "class_participation"]
assembler = VectorAssembler(inputCols=feature_cols, outputCol="features")
df_assembled = assembler.transform(df_indexed)
df_assembled.select("features", "label").show(5, truncate=False)
Pour la régression, on assemble les mêmes features mais la cible est total_score. On pourra réutiliser le même assembleur.

6. Normalisation et standardisation

Manipulation 4 — MinMaxScaler

MinMaxScaler ramène chaque feature dans l'intervalle [0, 1].

  1. Importer MinMaxScaler.
  2. Créer un scaler avec inputCol="features" et outputCol="features_scaled".
  3. Ajuster le scaler sur les données assemblées puis transformer.
  4. Afficher quelques lignes pour vérifier que les valeurs sont bien dans [0, 1].
from pyspark.ml.feature import MinMaxScaler

minmax = MinMaxScaler(inputCol="features", outputCol="features_scaled")
minmax_model = minmax.fit(df_assembled)
df_minmax = minmax_model.transform(df_assembled)
df_minmax.select("features", "features_scaled").show(5, truncate=False)

Manipulation 5 — StandardScaler

StandardScaler centre et réduit chaque feature (moyenne 0, écart-type 1).

  1. Importer StandardScaler.
  2. Créer un scaler avec inputCol="features", outputCol="features_std", withMean=True et withStd=True.
  3. Ajuster puis transformer les données assemblées.
  4. Comparer visuellement les valeurs obtenues avec celles de MinMaxScaler.
from pyspark.ml.feature import StandardScaler

std = StandardScaler(inputCol="features", outputCol="features_std", withMean=True, withStd=True)
std_model = std.fit(df_assembled)
df_std = std_model.transform(df_assembled)
df_std.select("features", "features_std").show(5, truncate=False)
À retenir : MinMaxScaler est adapté aux algorithmes sensibles à l'échelle et aux données bornées ; StandardScaler est préféré lorsque les features suivent approximativement une loi normale ou pour les modèles linéaires régularisés.

7. Division Train/Test (80/20)

Manipulation 6 — Split des données

  1. Diviser le DataFrame préparé en ensembles d'entraînement (80 %) et de test (20 %) avec randomSplit([0.8, 0.2], seed=42).
  2. Afficher le nombre de lignes de chaque ensemble.
  3. Conserver les DataFrames train et test pour la suite.
train, test = df_std.randomSplit([0.8, 0.2], seed=42)
print("Train :", train.count(), "| Test :", test.count())
On utilise ici df_std (features standardisées) pour la classification et la régression. On peut également refaire le split avec df_minmax pour comparer l'effet du scaling.

8. Classification avec LogisticRegression

Manipulation 7 — Entraînement du classifieur

  1. Importer LogisticRegression depuis pyspark.ml.classification.
  2. Créer un modèle avec featuresCol="features_std", labelCol="label", maxIter=100.
  3. Entraîner le modèle sur train.
  4. Générer les prédictions sur test avec model.transform(test).
  5. Afficher quelques lignes de prédictions (label, prediction, probability).
from pyspark.ml.classification import LogisticRegression

lr = LogisticRegression(featuresCol="features_std", labelCol="label", maxIter=100)
lr_model = lr.fit(train)
predictions = lr_model.transform(test)
predictions.select("label", "prediction", "probability").show(5, truncate=False)

Manipulation 8 — Évaluation : Accuracy, F1, Precision, Recall

  1. Importer MulticlassClassificationEvaluator.
  2. Calculer l'Accuracy, le F1-score, la Precision et le Recall (métriques accuracy, f1, weightedPrecision, weightedRecall).
  3. Afficher la matrice de confusion avec predictions.groupBy("label", "prediction").count().show().
  4. Interpréter les résultats : le modèle confond-il certaines classes (par exemple B et C) ?
from pyspark.ml.evaluation import MulticlassClassificationEvaluator

evaluator = MulticlassClassificationEvaluator(labelCol="label", predictionCol="prediction")
for metric in ["accuracy", "f1", "weightedPrecision", "weightedRecall"]:
    print(metric, "=", evaluator.evaluate(predictions, {evaluator.metricName: metric}))

predictions.groupBy("label", "prediction").count().orderBy("label", "prediction").show()

9. Régression linéaire avec LinearRegression

Manipulation 9 — Entraînement du régresseur

Pour la régression, la cible est total_score. On assemble les mêmes features et on standardise.

  1. Créer un DataFrame df_reg avec features_std et total_score renommé en label_reg.
  2. Diviser en train_reg et test_reg (80/20, seed=42).
  3. Importer LinearRegression depuis pyspark.ml.regression.
  4. Entraîner le modèle sur train_reg.
  5. Générer les prédictions sur test_reg.
  6. Afficher les coefficients et l'intercept du modèle.
from pyspark.ml.regression import LinearRegression

df_reg = df_std.withColumnRenamed("total_score", "label_reg")
train_reg, test_reg = df_reg.randomSplit([0.8, 0.2], seed=42)

linreg = LinearRegression(featuresCol="features_std", labelCol="label_reg")
linreg_model = linreg.fit(train_reg)
pred_reg = linreg_model.transform(test_reg)

print("Coefficients :", linreg_model.coefficients)
print("Intercept :", linreg_model.intercept)
pred_reg.select("label_reg", "prediction").show(5)

Manipulation 10 — Évaluation : RMSE, MAE et R²

  1. Importer RegressionEvaluator.
  2. Calculer le RMSE, le MAE et le R² (métriques rmse, mae, r2).
  3. Interpréter : un R² proche de 1 indique un bon ajustement ; un RMSE faible indique des prédictions proches des valeurs réelles.
from pyspark.ml.evaluation import RegressionEvaluator

reg_eval = RegressionEvaluator(labelCol="label_reg", predictionCol="prediction")
for metric in ["rmse", "mae", "r2"]:
    print(metric, "=", reg_eval.evaluate(pred_reg, {reg_eval.metricName: metric}))
